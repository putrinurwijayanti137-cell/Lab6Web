# Lab6Web --- JavaScript DOM dan Event Handling

## Tujuan

Memahami DOM, pemilihan dan perubahan elemen HTML, event handling,
perubahan gaya CSS, penghitung karakter, validasi formulir, dan
interaksi daftar tugas.

## Struktur File

``` text
lab6_dom_event/
├── index.html
├── style.css
├── script.js
├── README.md
└── image/
    ├── eksperimen-sembunyi-tampil
    ├── latihan-1-2-dom-click
    ├── latihan-1-2-dom-click2
    ├── latihan-3-gaya-css
    ├── latihan-4-penghitung-karakter
    ├── latihan-5-email-tidak-valid
    ├── latihan-5-nama-kosong
    └── latihan-6-tambah-selesai-hapus
```

## Cara Menjalankan

1.  Buka folder `lab6_dom_event` di Visual Studio Code.
2.  Pastikan `index.html`, `style.css`, dan `script.js` berada dalam
    folder yang sama.
3.  Pastikan `index.html` menghubungkan file CSS dan JavaScript.
4.  Buka `index.html` melalui browser atau gunakan Live Server.
5.  Uji tombol, input, daftar tugas, dan formulir.
6.  Periksa Developer Tools bagian Console jika terjadi kesalahan.

## Langkah Kerja

1.  Membuat struktur HTML, CSS, dan JavaScript.
2.  Mengubah teks menggunakan DOM.
3.  Menambahkan event klik untuk memperbarui pesan.
4.  Mengubah gaya paragraf menggunakan `classList`.
5.  Menghitung jumlah karakter saat mengetik.
6.  Menguji validasi nama dan email.
7.  Membuat daftar tugas yang dapat ditambahkan, ditandai selesai, dan
    dihapus.
8.  Membuat tombol sembunyikan/tampilkan paragraf.
9.  Menyimpan screenshot hasil pengujian ke folder `image`.

## Kesimpulan

JavaScript dapat digunakan untuk mengubah elemen HTML melalui DOM,
merespons tindakan pengguna dengan event, mengubah tampilan menggunakan
class CSS, dan memvalidasi input formulir.
